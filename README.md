# Teamkit

Mini-plateforme de packs et de codes pour les clubs. Support d'un test technique.

```bash
bin/setup          # installe, crée la base, charge les seeds
bin/dev            # http://localhost:3000
bundle exec rspec
```

Comptes de démonstration : `manager@as-lyon.test` et `manager@rc-nantes.test`, mot de passe `password`.
Page membre : http://localhost:3000/as-lyon/redeem (code `ASLYON-U13-006`).
Emails : http://localhost:3000/letter_opener.

Lire `docs/domain.md` (règles métier) et `CONTRIBUTING.md` (conventions).
